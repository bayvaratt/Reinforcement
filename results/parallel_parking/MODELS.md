# Saved DDPG Models

These are trained DDPG agent checkpoints for parallel parking, categorised by performance tier: **OPTIMAL** models maximise success-crash differential, **HIGH_SUCCESS** models achieve >70% success rate, **SAFE** models maintain <20% crash rate, **MILESTONE** models meet both 60%+ success and 30%- crash thresholds, with each filename encoding success/crash metrics and training timestamp for easy identification and comparison. In this folder, there are an array of saved models in this hierarchy so you can test them out by inserting the relative path
